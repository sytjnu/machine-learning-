Chapter Guide

机器学习章节关键知识点分析与例题

本栏目按照课程主要章节整理，帮助学生把“概念、公式、算法流程、计算题、编程上机”串起来。每章都补充重点拆解、考试抓手、常见误区和配套例题。

第 1 章

机器学习概述与任务类型

关键知识点分析：区分监督学习、无监督学习和强化学习；理解分类与回归的区别；能从业务描述中判断任务类型。

  • 有标签且预测离散类别：分类。
  • 有标签且预测连续数值：回归。
  • 无标签并寻找群体结构：聚类或降维。

重点拆解

机器学习不是“把规则写死”，而是让模型从历史数据中学习输入与输出、样本与结构、状态与反馈之间的规律。判断任务类型时，先看有没有标签，再看输出是什么形式。

考试抓手

题目常把任务藏在真实场景里，例如故障预测、疾病筛查、用户分群、价格预测。看到“是否、类别、风险等级”多半是分类；看到“价格、销量、温度”等连续数值多半是回归。

判断口诀：先问“有没有标签”，再问“输出是类别还是数值”。
例题与参考答案

例题：根据学生历史作业、出勤和测验成绩，预测其是否存在挂科风险，属于什么任务？

参考答案：监督学习中的分类任务，因为训练数据有历史标签，输出是“有风险/无风险”的离散类别。

第 2 章

数据预处理与数据划分

关键知识点分析：掌握缺失值处理、标准化/归一化、训练集/验证集/测试集划分；理解数据泄漏为什么会导致虚高结果。

  • 距离类算法常需要标准化。
  • 验证集用于调参，测试集用于最终评估。
  • 不能用测试集统计量参与训练预处理。

重点拆解

数据预处理决定模型能否“公平地看待”不同特征。标准化通常把特征变成均值约为 0、方差约为 1 的形式；归一化常把特征压缩到固定范围。二者都服务于减少量纲差异。

流程要求

更严谨的流程是先划分训练集、验证集和测试集，再只用训练集拟合标准化器，最后把同一个变换应用到验证集和测试集。这样才能避免测试集信息提前泄漏。

常见误区：先对全体数据做标准化，再划分数据集。这会让测试集统计信息进入训练过程。
例题与参考答案

例题：KNN 中同时使用“年龄”和“年收入”两个特征，为什么通常要做标准化？

参考答案：年收入数值范围通常远大于年龄，若不标准化，距离计算会被收入主导，导致年龄信息被弱化。

第 3 章

KNN 与距离度量

关键知识点分析：理解 KNN 的“懒惰学习”特点、欧氏距离计算、多数表决机制，以及 K 值对噪声和边界平滑程度的影响。

  • K 小：边界更灵活，但更容易受噪声影响。
  • K 大：结果更平滑，但可能欠拟合。
  • 预测阶段需要与训练样本计算距离，数据大时较慢。

算法流程

KNN 训练阶段几乎只是保存样本；预测时计算新样本到所有训练样本的距离，选出最近的 K 个邻居，分类任务做多数表决，回归任务做均值或加权均值。

计算重点

二维欧氏距离常考：d((x1,y1),(x2,y2)) = √((x1-x2)^2+(y1-y2)^2)。考试中要先算距离，再排序，再看最近 K 个样本的类别投票。

常见误区：只找到最近一个点就结束。题目若给 K=3 或 K=5，必须按 K 个邻居投票。
例题与参考答案

例题：已知 A(1,1)、B(2,1) 为类别 0，C(4,4)、D(5,4) 为类别 1。新样本 X(2,2)，当 K=3 时类别是什么？

参考答案：距离分别为 1、1、√8、√13，最近三点为 A、B、C，其中类别 0 两票，因此预测为类别 0。

第 4 章

线性模型与逻辑回归

关键知识点分析：线性回归预测连续值，逻辑回归用于分类概率建模；理解 Sigmoid 输出范围和阈值分类思想。

  • 线性组合：z = w^T x + b。
  • Sigmoid 将 z 映射到 [0, 1]。
  • 常用 0.5 作为二分类阈值，也可按业务调整。

重点拆解

线性回归直接输出连续值，逻辑回归则先得到线性得分 z，再通过 Sigmoid 函数把得分压到 0 到 1 之间，因此更适合表达“属于正类的概率”。

公式抓手

Sigmoid 函数为 σ(z)=1/(1+e^{-z})。当 z 越大，σ(z) 越接近 1；当 z 越小，σ(z) 越接近 0。分类阈值不一定永远是 0.5，医疗筛查等任务可根据漏诊代价调整。

考试常问：逻辑回归虽然名字有“回归”，但常用于分类。
例题与参考答案

例题：某逻辑回归模型输出概率 0.82，阈值为 0.5，应判为正类还是负类？

参考答案：判为正类，因为 0.82 大于阈值 0.5。

第 5 章

决策树、过拟合与集成学习

关键知识点分析：决策树通过降低不纯度进行划分；过深的树容易记住训练噪声；随机森林通过多树投票提升稳定性。

  • 节点划分常看信息增益、基尼指数等指标。
  • 训练集高分、测试集低分常提示过拟合。
  • 随机森林属于集成学习，能降低单棵树波动。

重点拆解

决策树每次选择一个特征和切分方式，使切分后的样本更“纯”。树越深，越能贴合训练集细节，但也越容易把噪声当成规律。

泛化理解

过拟合的典型表现是训练集很好、测试集明显变差。缓解方式包括限制最大深度、设置最小叶子样本数、剪枝、增加数据、正则化或使用随机森林。

随机森林 = 多棵树 + 样本/特征随机性 + 投票或平均。
例题与参考答案

例题：一棵树训练准确率 100%，测试准确率 62%，继续增加树深是否合适？

参考答案：不合适。该现象更可能是过拟合，应考虑剪枝、限制最大深度、增加数据或使用随机森林。

第 6 章

模型评估指标

关键知识点分析：掌握混淆矩阵 TP、FP、FN、TN；能计算 Accuracy、Precision、Recall、F1；理解类别不平衡时 Accuracy 的局限。

  • Precision = TP / (TP + FP)。
  • Recall = TP / (TP + FN)。
  • F1 是 Precision 和 Recall 的调和平均。

指标含义

Accuracy 看整体预测对了多少；Precision 看“预测为正的样本里有多少是真的正”；Recall 看“所有真实正样本里有多少被找出来”。F1 用来平衡 Precision 和 Recall。

场景判断

垃圾邮件过滤若误删正常邮件代价高，应重视 Precision；疾病筛查若漏诊代价高，应重视 Recall。类别极不平衡时，Accuracy 容易虚高，需要结合混淆矩阵分析。

F1 = 2PR / (P + R)，其中 P 为 Precision，R 为 Recall。
例题与参考答案

例题：TP=30，FP=10，FN=20，TN=40，计算 Precision 和 Recall。

参考答案：Precision=30/(30+10)=0.75；Recall=30/(30+20)=0.60。

第 7 章

无监督学习：K-Means 与 PCA

关键知识点分析：K-Means 用距离把样本划分为 K 个簇；PCA 寻找最大投影方差方向，可用协方差矩阵特征向量理解。

  • K-Means 的 K 需要人为设定或结合方法选择。
  • PCA 不使用标签，是无监督降维方法。
  • 第一主成分对应最大特征值的特征向量。

K-Means 拆解

K-Means 先选 K 个中心，再反复执行“按距离分配样本到最近中心”和“重新计算每个簇中心”两步，直到中心变化很小或达到最大迭代次数。

PCA 拆解

PCA 的目标是找一个单位方向，使样本投影到该方向后的方差最大。推导时常写成 max w^T S w，约束 w^T w=1，最终得到 Sw=λw。

常见误区：PCA 保留的是最大方差方向，不一定是最适合分类的方向。
例题与参考答案

例题：协方差矩阵 S = diag(5, 2)，第一主成分方向是哪一个？

参考答案：第一主成分方向为 [1,0]^T，因为该方向对应最大特征值 5。

第 8 章

神经网络与 CNN 基础

关键知识点分析：理解神经网络的层结构、激活函数、卷积核、步长、Padding、池化；能手算小矩阵卷积和池化输出。

  • ReLU(x)=max(0,x)，常用于引入非线性。
  • 卷积输出尺寸与输入、卷积核、步长、Padding 有关。
  • 最大池化取窗口最大值，常用于降维和增强局部鲁棒性。

卷积理解

卷积核像一个小窗口，在图像或特征图上滑动。每个位置做对应元素乘加，再加偏置，经过激活函数得到输出特征值。多个卷积核会产生多个输出通道。

尺寸公式

若输入边长为 N，卷积核大小为 F，Padding 为 P，步长为 S，则输出边长为 (N-F+2P)/S+1。计算题要注意结果必须是整数。

最大池化只取窗口最大值；平均池化才取平均值。
例题与参考答案

例题：输入 5×5，卷积核 3×3，步长 1，Padding 为 0，输出空间尺寸是多少？

参考答案：输出边长为 (5-3+2×0)/1+1=3，因此输出尺寸为 3×3。
