第 1 章

机器学习概述与任务类型

本章解决“什么是机器学习、机器学习能解决什么问题、如何根据题意判断任务类型”三个基础问题。

参考链接： 机器学习算法动态图目录 训练/验证/测试集动态图

背景

传统程序依赖人工写规则，而机器学习依赖数据。只要问题中存在大量历史样本，并且规律难以用固定规则完整写出，就适合考虑机器学习方法。例如设备故障预测、用户分群、垃圾邮件识别、图像辅助诊断等。

知识点

  • 监督学习：训练数据有输入和标签，学习从输入到标签的映射。
  • 分类：输出是离散类别，如是否故障、是否患病、邮件是否垃圾。
  • 回归：输出是连续数值，如房价、销量、温度、风险分数。
  • 无监督学习：数据没有标签，目标是发现结构，如聚类、降维。
  • 强化学习：智能体通过动作与环境交互，根据奖励学习策略。

理论

机器学习可粗略理解为从数据集 D 中学习一个模型 f，使其对未见样本也有较好预测或解释能力。监督学习通常学习 y = f(x)；无监督学习更关注样本之间的结构，如相似性、簇、低维表示。

判断任务类型：先看有没有标签，再看输出是类别、数值，还是结构。

5 道例题

  1. 根据传感器数据预测机器是否故障，属于什么任务？

    监督学习中的分类任务，因为输出是“故障/正常”。

  2. 根据房屋面积、楼层、位置预测房价，属于什么任务？

    监督学习中的回归任务，因为房价是连续数值。

  3. 把没有标签的客户按消费行为分成若干群体，属于什么任务？

    无监督学习中的聚类任务。

  4. 让机器人通过奖励学习走迷宫，属于什么学习？

    强化学习，因为它通过动作、环境反馈和奖励学习策略。

  5. “写很多 If-Else 规则”是否就是机器学习？

    不是。机器学习强调从数据中自动学习规律，而不是完全由人工硬编码规则。

第 2 章

数据预处理与数据划分

本章关注模型训练前的准备工作，包括缺失值处理、特征缩放、数据集划分和数据泄漏防范。

参考链接： 特征标准化交互图 数据划分动态图

背景

真实数据常有缺失、异常、单位不统一、类别变量和重复记录。预处理并不是附属步骤，而是决定模型是否可靠的基础。对 KNN、K-Means、逻辑回归等算法来说，数据尺度和划分方式会明显影响结果。

知识点

  • 缺失值处理：删除、均值/中位数填充、模型填充等。
  • 特征缩放：标准化、归一化，减少量纲影响。
  • 类别变量：可使用独热编码等方式转为数值特征。
  • 数据划分：训练集用于拟合，验证集用于调参，测试集用于最终评估。
  • 数据泄漏：测试集或未来信息提前进入训练流程，会导致结果虚高。

理论

标准化常用公式为 z = (x - mean) / std，归一化常用公式为 x' = (x - min) / (max - min)。实际建模中，应只在训练集上计算 mean、std、min、max，再应用到验证集和测试集。

常见误区：先用全体数据做标准化，再划分训练集和测试集。这会把测试集统计信息泄漏给模型。

5 道例题

  1. KNN 中年龄范围 18-70，收入范围 0-100000，为什么要标准化？

    否则收入在距离计算中占主导，年龄影响被压低。

  2. 测试集能否参与调参？

    不能。调参应使用验证集，测试集用于最终评估。

  3. 训练集准确率 96%，测试集准确率 95%，是否一定过拟合？

    不一定。二者接近，通常泛化差距较小。

  4. 某特征缺失率为 2%，可否直接删除缺失样本？

    可以考虑删除，但需确认删除不会引入明显偏差。

  5. 标准化后特征均值通常接近多少？

    接近 0，标准差接近 1。

第 3 章

KNN 与距离度量

KNN 是理解距离、相似性、局部决策边界和预测复杂度的好入口，也是考试中常见的基础计算题来源。

参考链接： KNN 最近邻动态图 K 值与决策边界动画

背景

KNN 的思想非常直观：一个样本的类别往往与它附近样本的类别相似。它训练阶段几乎不建立显式模型，而是在预测时查找最近邻，因此也被称为懒惰学习方法。

知识点

  • 欧氏距离：二维点距离常用 sqrt((x1-x2)^2+(y1-y2)^2)。
  • K 值：K 小容易受噪声影响，K 大可能过度平滑。
  • 分类决策：最近 K 个邻居多数表决。
  • 回归决策：最近 K 个邻居取均值或加权均值。
  • 缺点：预测阶段需要和大量训练样本算距离，速度较慢。

理论

KNN 没有复杂训练过程，但高度依赖距离度量和特征尺度。对高维数据，距离可能变得不稳定，且存储和计算成本较高。常见改进包括标准化、选择合适 K、使用 KD-Tree 或近似最近邻方法。

解 KNN 计算题：算距离 → 排序 → 取最近 K 个 → 多数表决。

5 道例题

  1. A(0,0)、B(2,0) 属 0 类，C(4,0) 属 1 类，X(1,0)，K=1 类别？

    到 A、B 距离均为 1，若题目未给平票规则，应说明存在平票，需要约定规则。

  2. X(2,2) 到 A(1,2) 的欧氏距离是多少？

    sqrt((2-1)^2+(2-2)^2)=1。

  3. K 越小是否越稳定？

    不是。K 小更容易受噪声点影响。

  4. KNN 训练慢还是预测慢？

    通常训练很轻，预测较慢。

  5. K=3 时最近邻类别为 0、1、1，预测类别？

    类别 1，因为多数表决中类别 1 有两票。

第 4 章

线性模型与逻辑回归

本章帮助学生理解线性组合、概率输出、分类阈值和梯度下降的基本思想。

参考链接： 线性回归动态图 逻辑回归 Sigmoid 动画

背景

线性模型是许多复杂模型的基础。线性回归用于连续值预测，逻辑回归虽然名字中有“回归”，但常用于二分类。它们简单、可解释，是机器学习入门阶段必须掌握的模型。

知识点

  • 线性组合：z = w^T x + b。
  • 线性回归：直接预测连续值。
  • 逻辑回归：用 Sigmoid 把 z 映射为概率。
  • 阈值分类：概率大于阈值判为正类。
  • 梯度下降：沿损失函数下降最快方向迭代更新参数。

理论

Sigmoid 函数为 sigma(z)=1/(1+exp(-z))，输出范围在 0 到 1 之间，可解释为正类概率。梯度下降更新一般写作 theta = theta - eta * gradient，其中 eta 是学习率。

常见误区：认为逻辑回归只能处理线性可分数据。实际中它是线性决策边界的基础模型，可配合特征工程增强表达能力。

5 道例题

  1. 逻辑回归输出 0.73，阈值 0.5，预测类别？

    正类。

  2. Sigmoid 输出范围是多少？

    0 到 1。

  3. 预测明日温度更适合分类还是回归？

    回归，因为温度是连续数值。

  4. 医疗筛查中想减少漏诊，应提高还是降低正类判定阈值？

    通常降低阈值以提高 Recall，但可能增加误报。

  5. 梯度下降的目标是什么？

    寻找使损失函数较小的模型参数。

第 5 章

决策树、过拟合与集成学习

本章把树模型、泛化能力和随机森林联系起来，重点理解“训练好不等于测试好”。

参考链接： 决策树分裂动态图 随机森林集成动画

背景

决策树通过一系列问题把样本划分到叶节点，形式接近人类判断流程，因此可解释性较强。但树越深越容易记住训练集细节，导致测试集性能下降。

知识点

  • 节点划分目标：让子节点更纯。
  • 划分指标：信息增益、增益率、基尼指数等。
  • 过拟合表现：训练集分数高，测试集分数明显低。
  • 缓解方式：剪枝、限制深度、正则化、增加数据。
  • 随机森林：多棵树投票或平均，降低单棵树波动。

理论

决策树每次划分都在降低不纯度。随机森林进一步引入样本随机抽样和特征随机选择，使树之间有差异，最后通过集成降低方差。

随机森林核心：Bootstrap 样本 + 随机特征 + 多树投票。

5 道例题

  1. 训练准确率 100%，测试准确率 60%，是什么现象？

    过拟合。

  2. 继续增加树深能否缓解过拟合？

    通常不能，可能更严重。

  3. 随机森林属于什么学习思想？

    集成学习。

  4. 决策树划分节点通常为了什么？

    降低不纯度，让子节点样本更纯。

  5. 列举两种缓解过拟合方法。

    限制树深、剪枝、增加数据、正则化、提前停止等。

第 6 章

模型评估指标

本章重点是混淆矩阵与分类指标的计算和解释，尤其要理解不同业务场景下指标选择不同。

参考链接： Precision/Recall 动态图 ROC 与 AUC 动画

背景

模型不能只看“准确率高不高”。在疾病筛查、欺诈检测、垃圾邮件过滤等场景中，不同错误类型的代价不同，因此需要混淆矩阵、Precision、Recall 和 F1 共同分析。

知识点

  • TP：真实为正，预测为正。
  • FP：真实为负，预测为正。
  • FN：真实为正，预测为负。
  • TN：真实为负，预测为负。
  • Accuracy、Precision、Recall、F1 是常考计算指标。

理论

Accuracy=(TP+TN)/(TP+FP+FN+TN)，Precision=TP/(TP+FP)，Recall=TP/(TP+FN)，F1=2PR/(P+R)。类别不平衡时，Accuracy 容易误导，应结合 Recall、Precision 和混淆矩阵。

常见误区：把 Precision 和 Recall 混淆。Precision 看预测为正的结果是否可靠，Recall 看真实正类是否被找全。

5 道例题

  1. TP=40，FP=10，FN=20，TN=130，Accuracy 是多少？

    (40+130)/200=0.85。

  2. 同上，Precision 是多少？

    40/(40+10)=0.80。

  3. 同上，Recall 是多少？

    40/(40+20)=0.667。

  4. 疾病筛查更关注 Precision 还是 Recall？

    通常更关注 Recall，因为漏诊代价高。

  5. 类别极不平衡时哪个指标容易误导？

    Accuracy。

第 7 章

无监督学习：K-Means 与 PCA

本章把聚类和降维放在一起：K-Means 关注样本分组，PCA 关注用更少维度保留主要变化方向。

参考链接： K-Means 迭代动态图 PCA 主成分动态图

背景

很多数据没有标签，但仍然有结构。例如客户行为数据可以分群，高维图像或文本特征可以降维可视化。无监督学习的目标不是预测标签，而是发现数据内部规律。

知识点

  • K-Means：指定 K 个簇，迭代更新样本分配和聚类中心。
  • SSE：样本到所属中心距离平方和，可用于观察聚类紧凑程度。
  • PCA：寻找最大投影方差方向，常用于降维。
  • 协方差矩阵：描述特征间共同变化关系。
  • 第一主成分：最大特征值对应的特征向量。

理论

K-Means 优化目标是让簇内样本尽量接近各自中心。PCA 的第一主成分可写为 max w^T S w, s.t. w^T w=1，拉格朗日推导得到 Sw=lambda w，因此主成分方向是协方差矩阵的特征向量。

PCA 第一主成分 = 最大特征值对应的特征向量。

5 道例题

  1. K-Means 中 K 表示什么？

    聚类簇数量或聚类中心数量。

  2. K-Means 会自动推导最佳 K 吗？

    不会，通常需要人为指定或结合肘部法等方法选择。

  3. PCA 是否需要标签？

    不需要，是无监督降维方法。

  4. S=diag(9,4)，第一主成分方向是什么？

    [1,0]^T，对应最大特征值 9。

  5. PCA 降到二维后分类准确率下降，可能原因？

    降维丢失了对分类有用的信息；最大方差方向不一定最有判别力。

第 8 章

神经网络与 CNN 基础

本章关注神经网络的基本组成，以及 CNN 中卷积、激活和池化的手算逻辑。

参考链接： 神经网络训练动态图 CNN 卷积与池化动画

背景

神经网络通过多层非线性变换学习复杂模式。CNN 特别适合图像等具有局部空间结构的数据，因为卷积核可以在不同位置共享权重，提取边缘、纹理和局部形状等特征。

知识点

  • 神经元：线性加权求和后接激活函数。
  • ReLU：max(0,x)，把负值截为 0。
  • 卷积核：局部窗口内做元素乘加。
  • Padding 与步长：共同影响输出尺寸。
  • 最大池化：每个窗口取最大值，实现降维。

理论

卷积输出边长为 (N-F+2P)/S+1，其中 N 为输入边长，F 为卷积核大小，P 为填充，S 为步长。多通道卷积会分别在每个通道乘加，再跨通道求和并加偏置。

常见误区：把最大池化当成求平均。最大池化取最大值，平均池化才取平均值。

5 道例题

  1. 输入 5×5，卷积核 3×3，S=1，P=0，输出尺寸？

    (5-3+0)/1+1=3，输出 3×3。

  2. ReLU(-2) 等于多少？

    0。

  3. 2×2 窗口 [[1,3],[2,0]] 最大池化结果？

    3。

  4. 卷积核数量通常决定输出什么？

    输出通道数。

  5. CNN 为什么适合图像？

    因为它利用局部连接和权值共享，能提取空间局部特征并减少参数量。
