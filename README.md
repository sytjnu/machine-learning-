# 机器学习基础课程网站

这是一个机器学习基础课程静态网站，包含：

- 上机编程题目
- 章节关键知识点分析与例题
- 期末复习题库
- 题库筛选与随机自测
- 上机提交规范
- 参考书目

## 上机作业提交规范

学生完成上机任务后，将代码、实验报告、结果图、运行说明等材料压缩为一个文件，命名格式为：

```text
姓名+学号.zip
```

例如：

```text
张三2025123456.zip
```

学生将个人压缩包提交给学委；学委收齐并核对名单后，将全班作业统一打包发送给任课老师。

## 参考书目

## 本地预览

直接用浏览器打开 `index.html` 即可。

题库已按“知识点相关、题面与数据不同”的原则编写，避免与期末试题完全一致。
